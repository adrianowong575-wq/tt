PÁGINA HTML ESTÁTICA

1. Sube TODO el contenido de esta carpeta a la raíz de tu repositorio de GitHub.
2. El archivo index.html debe quedar en la raíz.
3. En GitHub: Settings > Pages > Deploy from a branch > main > /root > Save.
4. Abre el enlace que GitHub Pages te entrega.

No necesitas app.py, Flask ni requirements.txt.
